# Spec: intent-goal-limits (this skill)

cost_class: reversible

## Intent

Avoid over-spec, over-build, and unagreed price, by making the value and cost balance computable by each person who bears a cost.

## Goal

A spec written with this skill climbs a ladder read from its ledger: Written (three parts, every cost with a bearer, every seat tagged, cost class declared), Closed (every irreversible seat asked; disagreeing seats both recorded, their limit kept open), Tested (a row shows the spec stopped or changed a build). The skill's fitness signal is the share of specs reaching Tested, not the count written.

## Limits

The balance between the value pursued and its cost. The skill is not worth using when any of these tips.

| Cost | Bearer (seat) | Seat | Balance as the bearer sees it |
| --- | --- | --- | --- |
| Specifying costs more than the build it guards | the authoring pair | filled | Two rounds then build; the fourth draft of this spec was the evidence |
| A seat filled by imagination and tagged filled | whoever ends on the limits side of a spec written with this skill | empty | |
| A category the world still argues about gets frozen into a spec | the people the category is applied to | empty | |
| Correction becomes harder than the wrong build it prevents | the builder who has to change the spec before the code | filled | Specs change only from ledger rows, never from another draft |

## Open

Two seats are empty and cannot be filled by the authors, since the authors are not the ones who end on the limits side of other people's specs. They stay empty until a spec written with this skill produces a row from such a person. The name of the skill is provisional. Cost class is reversible, including at publish: git commits on top. The irreversible cost of this skill lands when a spec written with it is applied to a person, and that is where its two empty seats get filled, by such a person.
